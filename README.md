# GREEN-API Chat

Тестовое задание на должность «Фронтенд разработчик React».

Веб-приложение для отправки и получения текстовых сообщений через [GREEN-API](https://green-api.com/) (инстанс Telegram).

## 🚀 Демо

[Ссылка на задеплоенное приложение](https://vera-fe.github.io/green-api-chat/)

## ✨ Возможности

- Ввод учётных данных (`idInstance`, `apiTokenInstance`) с сохранением в `localStorage`
- Ввод номера телефона получателя
- Отправка текстовых сообщений через метод `sendMessage`
- Получение входящих сообщений через метод `receiveNotification` (polling каждые 5 секунд)
- Отображение переписки в виде чата (исходящие — справа, входящие — слева)
- Автоматическая прокрутка к новому сообщению
- Отправка сообщения по нажатию Enter
- Всплывающие уведомления об успехе/ошибке с плавной анимацией
- Адаптивный дизайн в стиле Telegram

## 🛠️ Стек технологий

- **React 19** + **TypeScript**
- **Vite** — сборщик
- **CSS Modules** — изолированные стили
- **GREEN-API** — REST API для работы с Telegram

## 📦 Установка и запуск

### Требования
- Node.js 18+
- npm или yarn

### Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Vera-fe/green-api-chat.git

# 2. Перейти в папку проекта
cd green-api-chat

# 3. Установить зависимости
npm install

# 4. Запустить dev-сервер
npm run dev


## 🧪 Проверка работы приложения

1. Зарегистрироваться на [GREEN-API](https://green-api.com/).
2. Создать инстанс **Telegram** в личном кабинете.
3. Отсканировать QR-код для авторизации.
4. Скопировать `idInstance` и `apiTokenInstance` из личного кабинета.
5. Открыть [приложение](https://vera-fe.github.io/green-api-chat/).
6. Вставить ключи в соответствующие поля.
7. Ввести номер телефона получателя (например, `79991112233`).
8. Написать сообщение и нажать Enter или кнопку отправки.
9. Попросить кого-нибудь ответить вам в Telegram — сообщение появится в приложении слева.
